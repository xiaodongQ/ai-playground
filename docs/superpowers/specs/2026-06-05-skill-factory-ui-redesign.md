# Skill Factory UI重新设计规范

## 1. 概念与愿景

Skill Factory 是一个自动化开发工厂的控制台，面向的是需要高效管理 Skill 开发流程的技术人员。界面应该传递「温暖但专业」的气质——不是冷冰冰的深色代码工具，而是一个让人愿意每天使用的舒适工作台。暖白底色配合柔和的圆角和微妙的阴影层次，配合清晰的信息层级和流畅的交互细节。

## 2. 设计语言

### 美学方向
温暖专业风 —暖白底 (#fefce8 → #ffffff渐变背景) + 深色侧边栏 (#1e293b) + 柔和圆角卡片 + 微妙阴影。

### 色彩系统
```
背景主色:     #fefce8 (暖白，页面背景)
卡片底色:    #ffffff (纯白，卡片/内容区)
侧边栏背景:   #1e293b (深蓝灰，固定侧边)
侧边栏文字:   #ffffff / rgba(255,255,255,0.7)

主色调: #3b82f6 (蓝，操作按钮/进行中)
成功色:      #22c55e (绿，已完成)
警告色:      #f97316 (橙，待认领)
危险色:      #ef4444 (红，异常)
文字主色:    #1e293b (深色标题)
文字次要:     #888888 (灰色辅助文字)
边框色:      #e2e8f0 (浅灰线条)
```

### 字体
- 主字体: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- 代码: `'SF Mono', 'Fira Code', 'Consolas', monospace`
- 字号层级: 页面标题 18px / 卡片标题 16px / 正文 13px / 辅助11-12px

### 空间系统
- 页面内边距: 28px
- 卡片间距: 16px (gap)
- 卡片内边距: 20px
- 圆角: 卡片 12px / 按钮 8px / 标签 pill 型

### 动效
- 页面切换: 无动画，保留内容切换速度
- 模态框: fade-in 150ms ease-out
- 按钮 hover: opacity 0.85，transition 0.2s
- 表格行 hover: background #fafafa

## 3. 布局结构

### 整体架构
```
┌──────────────┬────────────────────────────────┐
│              │                                │
│   侧边栏 │         主内容区                 │
│  (200px)    │         (flex:1)                │
│              │                                │
│  · Logo     │   · 统计卡片行 │
│  · 导航     │   · 趋势图表 (Dashboard)        │
│  · 设置 │   · 任务列表 / 经验库列表        │
│              │                                │
└──────────────┴────────────────────────────────┘
```

### 侧边栏 (固定)
- 宽度 200px，深色背景 #1e293b
- Logo 区: "⚙️ Skill Factory" 白色大字
- 导航项: 总览 / 任务 / 经验库 / 自动化（当前高亮项有浅色背景 + 白色文字）
- 底部: 设置（低透明度）

### 主内容区
- 顶部统计卡片行: 4列网格（待认领 / 进行中 / 已完成 / 异常）
- 趋势图: 仅 Dashboard 页显示柱状图
- 列表区: 表格或卡片列表

### 响应式策略
- 当前版本仅支持桌面端（≥1024px）
- 暂不实现移动端适配

## 4. 页面与功能

### 4.1 总览 (Dashboard)
**统计卡片行** — 4 个等宽卡片，分别显示 pending / in_progress / archived / exception 数量，数字用对应状态色大字显示。

**趋势柱状图** — 最近 6天的任务处理量柱状图，横轴日期，柱子用橙色渐变。不显示图例。

**最新任务列表** — 最近 5 条任务，每条显示状态色圆点 + 标题 + 模块名 + 创建时间 + 状态 pill。点击整行打开任务详情模态框。

### 4.2 任务页 (Tasks)
**工具栏** — 状态下拉筛选 + 新建任务按钮。

**任务表格** — 列: 标题(+描述截断) / 状态 / 版本 / 创建时间 / 操作(查看/认领/归档)。操作按钮小尺寸。

**新建/详情模态框** — 表单字段: 标题 / 描述 / 关联经验ID / 模块 / 资源链接 / 验收标准。详情模式字段为只读，提交按钮隐藏。

### 4.3 经验库页 (Experiences)
**工具栏** — 模块搜索输入框 + 添加经验按钮。

**经验表格** — 列: 模块 / 关键词 / 适用场景 / 操作(查看/删除)。

**添加/详情模态框** — 字段: 模块* / 关键词 / 日志路径 / 工具命令 / 适用场景 / 日志样例 / 代码片段。

### 4.4 自动化页 (Automation)
占位页面，显示简要说明「自动化执行面板开发中」。

### 4.5 设置页 (Settings)
占位页面，显示简要说明。

## 5. 组件清单

### StatCard
- 白色圆角卡片，左上角标签(状态名，灰色小字)，中央大数字(状态色)
- 无 hover 效果
- 尺寸: 最小宽度 160px，flex 自适应

### StatusPill
- pill 型(全圆角)，背景用状态色 15% 透明度，文字用状态色
- pending: 橙色，in_progress: 蓝色，archived: 绿色，exception: 红色

### TaskRow
- 表格行，左侧8px 状态色圆点，标题 + 描述截断(单行省略号)
- hover:整行背景 #fafafa
- 操作按钮: 小尺寸，次要/警告/危险三种

### Modal
- 居中覆盖层，背景 rgba(0,0,0,0.5)
- 白色弹窗，圆角 16px，内边距 28px，最大宽度 600px
- 标题18px，字段组垂直排列
- 操作按钮行: 取消(secondary) + 提交(primary)

### NavItem
- 默认:透明度 0.7，白色文字
- 激活: 背景 rgba(255,255,255,0.15)，文字白色，无圆角
- hover: 透明度 0.85

### BarChart
- 6 根柱子，橙色渐变 (#fed7aa → #c2410c)
- 柱子宽度 flex:1，高度百分比映射
- 底部日期标签，11px 灰色

## 6. 技术实现

- 单文件 HTML + 内联 CSS + 内联 JS（无构建步骤）
- Google Fonts 不引入，使用系统字体栈
- 图标使用 Emoji 替代（⚙️ 📊 📋 📚⚡⚙️ 🔴🟠 🟡 🟢）
- 无外部图表库，柱状图用 CSS flex 实现
- API 基础路径为空字符串（同源），生产环境可通过 reverse proxy 代理
